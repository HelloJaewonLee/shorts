## 1. 영상별 제작 방법

### A. 원초적 인사이트: 가장 구체적인 제작 절차
**왜 일본인가:** 한국은 짜깁기형 쇼츠 경쟁이 심하지만 일본은 아직 적고, 인구도 더 많습니다. 일본어를 전혀 모르는데도 2주 만에 조회수 50만, 구독자 300명을 얻었다고 주장합니다.

**소스 찾기 (01:19)**
1. 해외 소재: 외국어로 유튜브나 틱톡을 검색하거나, 중국 플랫폼(더우인, 샤오홍슈, 웨이보)에서 찾습니다.
   - 그대로 올리면 저작권 문제가 생긴다고 본인도 경고합니다.
   - 대안으로 재해석(2차 창작), 원작자에게 메일로 허락 받기, 출처 표기, 원작자에게도 이득이 되는 구조를 제시합니다.
2. 불안하면 **크리에이티브 커먼즈 필터**로 찾으라고 권합니다.

**핵심 과제 두 가지 (03:09):** 일본어 나레이션과 일본어 자막입니다.
- 나레이션은 AI 음성, 자막 끊기와 타이밍은 GPT로 해결합니다.
- **GPT 프롬프트 구조** (영상에서 설명한 요소):
  1. 한국어 대본을 일본어로 번역하되 **자막용으로 아주 짧게 끊기** (한 줄에 2~3어절)
  2. **줄마다 번호 붙이기** (편집할 때 위치를 찾기 쉽도록)
  3. 각 줄은 **현지인이 실제로 쓰는 자연스러운 일본어**로 쓰고, 바로 아래에 **원문 한국어**를 붙이기 (내용 확인용)
  4. 문장이 끝나는 지점을 표시
  5. 마지막에 **일본어 전체를 이어 붙인 문단**을 따로 출력 (TTS에 한 번에 붙여넣기 위해)
  6. 대본은 "한국어 스크립트 시작 / 끝" 표시 사이에 넣기

**음성:** 타입캐스트 일본어 성우에 전체 문단을 넣고 음성을 내려받습니다.

**편집 (캡컷, 월 1만 원 정도):**
1. 원본 오디오를 추출해 삭제하고 TTS 음성을 넣습니다.
2. 캡션 → **이중 언어 캡션**(일본어 + 한국어)을 자동 생성하면 TTS 타이밍에 맞춰집니다.
3. GPT 대본과 대조해 오타를 고칩니다. 특히 고유명사를 확인합니다.
4. 자막은 **한 줄 안에** 들어가게 끊습니다.

**올린 뒤 흐름 (07:02):**
- 처음 약 6시간은 한국에 노출되어 시청 지속률이 낮습니다.
- 이후 일본으로 넘어가 유효 조회수 1만 정도에서 멈춥니다.
- 영상이 10개쯤 쌓이면 10만 이상 터지는 영상이 나오고, 48시간 넘게 유지됩니다.

**단점:** 한국보다 쇼츠 수익 단가가 절반 수준이고 편집 시간이 더 걸립니다. 그래서 한국에서 이미 잘 되는 사람에게는 권하지 않는다고 합니다.

### B. Into your life: 부연 설명형 (정책에 가장 가까운 방식)
**콘텐츠:** 해외 바이럴 영상(허술한 악기로 연주하는 음악, 과학 호기심 영상 등)에서 **핵심 구간만 잘라** 씁니다. 여기에 **장면 부연 설명을 일본어 자막과 TTS 음성으로** 입히고 효과를 넣습니다. 영상 길이는 20~29초입니다.

**성과 (주장):**
- 2025-10-11 채널 개설 후 2달 만에 구독자 9,000명, 영상 128개
- 하루 1개씩 올리고, 1개 만드는 데 30~60분
- 약 1,700달러 수익
- 최고 영상은 20초짜리로 780만 회

**번역:** 강사가 만든 **GPTs**를 씁니다. 기능은 다음과 같습니다.
- **타깃 연령대**(20~30대와 50대)에 맞춰 어투와 어미를 바꿉니다.
- 구어체로 현지화합니다.
- 가이드라인, 저작권, 정서 적합성을 점검합니다.

**중요한 교훈:** 일본어는 띄어쓰기를 하지 않습니다. 자막에 띄어쓰기를 넣었더니 조회수가 안 나왔다고 합니다.

**니치 좁히기:** 음악 → 클래식 → 금관악기 → 특정 지휘자·연주자처럼 좁혀 들어갑니다. 채널은 여러 개로 확장했습니다.

**원본 출처:** "AI가 찾아준다, 영상은 무한하다"고만 말하고 **라이선스 확인 과정은 언급하지 않습니다**. 위험 요소입니다.

### C. 원더휴먼 / 엘리B: CC 소스 + 구간 선택 + 일본식 연출
**소스 → 구간 선택 (09:43~11:20):**
1. 유튜브에서 키워드를 검색하고 **필터 → 크리에이티브 커먼즈**를 켭니다.
2. 조회수 좋은 롱폼을 고릅니다. 예시는 조회수 51만의 롱폼이었습니다.
3. 재생바에 마우스를 올리면 나오는 **'가장 많이 다시 본 구간' 그래프**에서 봉우리를 찾습니다.
4. 그 봉우리 구간(예: 3분 40초 부근, 21초 분량)만 잘라냅니다.

**Gemini Gem "일본어 번역 작가" (11:19~16:00):** 잘라낸 영상이나 원본 링크를 넣으면 아래를 출력합니다.
- 현지식 **제목 후보**와 그 한국어 뜻
- **설명글**(일본은 이모지가 잘 먹힘)과 **태그**
- **타임라인별로** 원문 → 한국어 번역 → **끊어 읽기 슬래시(/)가 들어간 일본어** 대사
- 원문이 영어여도 같은 형식으로 출력
- 줄이 너무 길면 줄바꿈 위치까지 알려줌

**일본식 연출:**
- 자막: 크고 화려하게. 노랑·빨강·초록, 오락실 게임 같은 감성, 약간 촌스러울수록 좋다고 합니다.
- **일본에서 쓰는 효과음**을 단어나 동작마다 넣습니다. 웃음 표현 "www"도 씁니다.
- **퀄리티보다 '일본이 좋아하는 결'**이 중요하다고 합니다. 트렌드를 좇지 말라는 조언도 있습니다.
- 일본에서 잘 되는 카테고리 예: **퍼즐·수수께끼**. 댓글 토론이 붙어 반복 재생과 시청 지속률이 오릅니다.

**노출:** VPN은 필요 없습니다. 일본어로 만들면 일본에 노출됩니다.

**수익 (주장):**
- 한 채널 누적 2.9억 회, 5,700만 원
- 영상 1개 948만 회, 158만 원
- 업로드를 멈춰도 조회수가 계속 나온다고 합니다
- 연 누적 2.5억 원

**확장:** 직원과 프리랜서가 대본, 소재, 업로드를 맡습니다. 본인은 하루 2시간 시장과 카테고리를 분석합니다.

**위험:** 첫 예시가 **한국 아이돌 쇼츠를 일본어로 다시 자막 입힌 것**이었습니다. 이는 CC가 아닌 남의 영상이라 저작권 위험이 큽니다.

### D. 워크멘터리 / 샤샤룽: 풍경 + 음악형
**콘텐츠:** 11~18초 풍경 영상에 음악을 깔고 일본어 제목을 붙입니다. 편집은 거의 없습니다.

**성과 (주장):**
- 영상 1개가 1.6억 회, 예상 수익 1,550만 원, 이 영상 하나로 실버 버튼
- 2026년 1월 시작, 월 1.4만~3만 달러

**소스:** 틱톡 풍경 영상입니다. **원작자에게 연락해 허락**을 받는데, 대부분 계정 노출(출처 표기)을 조건으로 허용한다고 합니다.

**도구:**
- 자체 다운로더(샤오홍슈, 틱톡, 유튜브, 인스타그램 지원)
- Gem "조회수 폭발 제목 에디터": 일본 인터넷 말투로 제목을 만듭니다. 예: "〜な件について" 같은 표현
- 캡컷 작업 순서:
  1. 9:16으로 바꾸고 상단에 검은 제목 바를 둡니다.
  2. 굵고 가독성 좋은 폰트에 색을 넣습니다.
  3. **유명 곡 음원**에 에코를 넣습니다.
  4. 일본어·영어 가사 자막을 같은 위치에 겹칩니다.

**위험:** **상업 음원 사용**은 CC와 무관한 음악 저작권 문제입니다. 쇼츠 수익 배분에서도 음원 라이선스 비용이 먼저 빠집니다. 가사 번역 자막도 저작물 이용이라 위험합니다.

**운영:** 편집은 프리랜서가 맡고, 본인은 하루 30~60분 피드백과 업로드만 합니다. 디하클 무료 강의로 시작했다고 합니다.

## 2. 네 편(+ 처음 분석한 아스트라 영상)의 공통 패턴

1. **일본을 노리는 이유:** 시장이 크고 짜깁기형 경쟁이 덜하다고 봅니다. 일본어로만 만들면 VPN 없이 일본에 노출된다고 합니다(A, C, D 공통).
2. **일본어를 몰라도 되게 하는 장치:** 모두 **LLM에 고정된 번역 틀(GPT 프롬프트, GPTs, Gemini Gem)**을 씁니다. 공통 출력 요소는 다음과 같습니다.
   - 현지 구어체, 타깃 연령에 맞춘 어투
   - 자막용 짧은 줄 나눔과 끊어 읽기 표시
   - 줄 번호, 확인용 한국어 병기
   - TTS용으로 이어 붙인 전체 문단
   - 일본식 제목·설명(이모지 포함)·태그
3. **음성:** 타입캐스트 일본어 TTS(A, B)
4. **편집:** 캡컷, 이중 언어 자동 캡션, 굵은 폰트, **일본식 효과음**, 상단 제목 바. 일본어 자막은 **띄어쓰기 없이**.
5. **구간 선택:** '가장 많이 다시 본 구간' 그래프의 봉우리(C). 영상 길이는 **11~30초**가 대부분.
6. **운영:** 하루 1개 이상 꾸준히 올리고, 니치를 좁혀 채널을 여러 개 만들고, 익숙해지면 프리랜서에게 외주를 줍니다.
7. **수익 구조:** 네 편 모두 **강의 모집 퍼널**입니다. 미끼는 Gem, 효과음 팩, 다운로더입니다. 수익 인증은 검증할 수 없습니다.

## 3. 조사 보고서와 충돌하는 부분

| 영상에서 권한 방식 | 조사로 확인한 위험 |
|---|---|
| 한국 쇼츠(아이돌 등)를 일본어 자막으로 다시 올리기 (C) | 남의 저작물입니다. 번역·자막만 바꾼 영상은 재사용 콘텐츠로 수익화가 거절될 가능성이 큽니다 |
| 유명 곡을 깔고 가사 번역 자막 넣기 (D) | 음악 저작권(Content ID) 문제가 있고, 음원 라이선스 비용만큼 수익 배분이 줄어듭니다 |
| "AI가 원본을 찾아준다" (B) | 라이선스 확인이 없습니다. CC 표시가 되어 있어도 업로더가 남의 영상을 CC로 잘못 올렸을 수 있습니다 |
| 템플릿으로 하루 여러 개 대량 생산 | 2025-07 개편된 '진정성 없는(inauthentic) 콘텐츠' 정책이 겨냥하는 형태입니다 |

**우리 계획(CC-BY + 일본)에 가장 잘 맞는 것은 B의 '부연 설명형'과 C의 'CC 필터 + 다시 본 구간 선택'을 합친 방식입니다.** 원본을 번역만 하지 않고 **일본어 해설(補足解説) 나레이션을 새로 쓰면** 변형 요건을 채울 근거가 생깁니다. 이는 조사 보고서의 "번역이 아닌 독자 해설을 포함한 변형 요소 최소 두 가지" 권고와도 맞습니다.

## 4. 프로그램에 반영할 것

| 영상의 노하우 | 프로그램 기능 |
|---|---|
| CC 필터 검색 (A, C) | `search.list videoLicense=creativeCommon`으로 찾고, `videos.list`로 라이선스를 재확인한 뒤 증거(JSON·해시·시각)를 저장 |
| 다시 본 구간 그래프 (C) | yt-dlp 메타데이터의 `heatmap` 값으로 봉우리 구간을 후보로 올림. **실제 확인 결과 영상 A에서 100개 구간 값이 나옴** (조회수가 적은 영상에는 없음) → 없으면 Claude 선별로 대체 |
| 번역 틀 (A 프롬프트, C Gem) | `localize` 단계로 구현: 부연 해설 나레이션 작성(번역 아님) → 자막용 짧은 줄 + 끊어 읽기 → 한국어 병기(검수용) → TTS용 전체 문단 → 제목 후보·설명(이모지)·태그 |
